# Web Development Training Projects 🚀

This repository contains a collection of beginner-friendly web development projects built using **HTML, CSS, and JavaScript**. 
These projects were created as part of my learning journey to improve my front-end development skills and understand the fundamentals of web application development.

## 📌 Projects Included

### 🔳 Online QR Code Generator
Generate QR codes instantly from text or URLs using JavaScript.

**Features:**
- Generate QR codes in real-time
- User-friendly interface
- Fast and responsive design

### 🧮 Simple Calculator
A basic calculator that performs common arithmetic operations.

**Features:**
- Addition, subtraction, multiplication, and division
- Clean and responsive UI
- Interactive button controls

### 🔐 Simple Login Page
A modern login page design built with HTML and CSS.

**Features:**
- Responsive layout
- Attractive user interface
- Beginner-friendly implementation

### 🌡️ Temperature Converter
Convert temperature values between Celsius, and Fahrenheit.

**Features:**
- Instant conversions
- Easy-to-use interface
- Accurate calculations
